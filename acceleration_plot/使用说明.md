# 三轴加速度实时曲线

## 当前报警版本

- 每秒读取、输出并判断一次三轴加速度（替代下文旧版每秒50组说明）。
- 当 Z > 8 或 Z < -8 m/s² 时触发；等于 ±8 不触发。包含重力，静止摆放方向也会影响结果。
- 超标期间声光输出每250毫秒开关一次，UNO板载灯同步闪烁；下一次有效读数满足 |Z| ≤ 8 即停止。两次采样之间的短暂变化可能错过。
- 断开USB后连接报警模块：VCC → UNO 5V，GND → UNO GND，IN → UNO D8。传感器保持原四线连接。
- 根据实物“未超标时常响”的反馈，报警模块已改为低电平触发：IN 为 LOW 时报警，HIGH 时关闭。修改后需验证正常时安静、超标时声光闪烁。
- 传感器读取失败时输出 ERROR 并关闭报警输出，故障状态不代表加速度正常。
- 串口绘图器依然使用 COM5、115200 波特率，X/Y/Z 单位 m/s²。

## 当前四线临时测试（以本节为准）

按用户当前接线：模块 5V → UNO 5V，GND → GND，SDA → A4，SCL → A5；CS、SDO 暂不外接。下方六线加转换器表是另一种方案，不与此方案混接。

程序直接使用 Wire，初始化后关闭 UNO SDA/SCL 的内部上拉，不调用可能重新初始化总线的传感器库。依次检测 0x53 和 0x1D，并验证设备 ID。若模块默认 CS/SDO 状态不能支持通信，会持续输出 ERROR；此时需重新检查模式选择引脚。该直连方案是临时实物测试，并未保证电平余量和长期稳定性。

## 硬件

沿用此前讨论的双向 I²C 电平转换方案。当前传感器模块板的供电节点尚未实测确认；先确认模块 3V3 对 GND 约为 3.3V，再进行通信联调。不要将传感器通信线直接拉到 5V。

断电接线：

| 接口 | 连接 |
| --- | --- |
| UNO A4 | 转换模块 HV1 |
| UNO A5 | 转换模块 HV2 |
| UNO 5V | 转换模块 HV、传感器模块标注的 5V 输入 |
| UNO GND | 转换模块 GND、传感器 GND |
| 传感器 3V3 | 转换模块 LV、传感器 CS |
| 传感器 SDA | 转换模块 LV1 |
| 传感器 SCL | 转换模块 LV2 |
| 传感器 SDO | GND，地址选择为 0x53 |

此表沿用此前根据匹配十针模块资料给出的供电方案，须与实物核对。VS、IN1、IN2 暂不外接；UNO 的 3.3V 电源脚不接入此方案。报警模块暂时不用。

## 打开曲线

1. 用 Arduino IDE 打开本目录的 acceleration_plot.ino。
2. 用 USB 数据线连接 UNO。开发板选择 Arduino Uno，并选择对应 COM 端口。
3. 点击上传。上传完成后关闭串口监视器，打开“工具 → 串口绘图器”。
4. 波特率选择 115200，勾选 X、Y、Z。
5. 先放稳，再缓慢倾斜和轻摇传感器，观察三条曲线。

读数单位为 m/s²，每秒输出约 50 组。输出包含重力：平放时，某一轴接近正负 9.8，其他两轴接近 0 是正常现象；具体取决于安装方向。本程序用于初步可视化，不用于验证切削振动频谱或刀具磨损。

若没有曲线，先查看串口监视器（同样选择 115200）。出现 ERROR 表示未识别到 0x53 地址的传感器，应检查供电、共地、SDA/SCL、电平转换和 CS/SDO。串口绘图器与串口监视器不要同时占用端口。
